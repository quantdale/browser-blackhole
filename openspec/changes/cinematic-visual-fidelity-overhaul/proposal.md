# Proposal — Cinematic Visual Fidelity Overhaul

Cosmic Atlas has a strong physics/data and lifecycle foundation, but its
secondary destinations still read as prototype diagrams: flat discs, single
line strips, sparse hard points, and black voids. This campaign introduces a
shared procedural representation layer and then applies it destination by
destination, beginning with Stellar Explosion.

The campaign is intentionally not a physics rewrite. It preserves the
validated Schwarzschild/Kerr/observer paths, the neutron-star surface-ray
contract, the DATA_DRIVEN merger/collision artifacts, and the documented
procedural models. Visual layers consume resolved outputs and are labeled when
illustrative.

Success means a materially richer cinematic mode, a restrained scientific
mode, stable deterministic captures, equal-or-better governed work behavior,
WebGPU/WebGL2 compatibility, bounded resources, and a truthful final visual
certification.
