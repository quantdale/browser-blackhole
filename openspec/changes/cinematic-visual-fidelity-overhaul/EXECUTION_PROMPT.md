## Mission

Raise the entire Cosmic Atlas from a diagnostic/prototype presentation to a
modern, cinematic real-time experience while preserving the project's
scientific contracts, deterministic behavior, performance governance,
WebGPU/WebGL2 compatibility, and explicit resource ownership.

This is a representation-layer campaign. Authoritative physics, reference
data, dataset interpolation, unit conventions, termination classifications,
timeline semantics, and fidelity disclosures are not to be altered for
appearance. Cinematic settings are display/presentation choices and must never
be presented as physical model output.

The first complete vertical slice is Stellar Explosion. It must establish the
shared procedural representation primitives, validate them against the
existing deterministic explosion model, and pass its full browser/unit/golden
gate before the layer is propagated to the other destinations.

## Required dependency order

1. Baseline and visual audit; create the campaign evidence surfaces.
2. Shared deterministic representation primitives and cinematic display path.
3. **Stellar Explosion full-quality slice and validation gate.**
4. Shared volume/particle/ribbon/backdrop hardening proven on both backends.
5. Compact Merger and Tidal Disruption.
6. Neutron Star and Quasar/AGN.
7. Black-Hole Merger and Galaxy Collision.
8. Black Hole non-regression and transition/UX/accessibility verification.
9. Resource/performance certification and final visual review.

Do not parallelize edits to shared shader/material contracts. The orchestrator
owns integration and final validation.

## Non-negotiable invariants

- Preserve `r_g = GM/c^2`, Schwarzschild/Kerr conventions, observer/tetrad
  semantics, neutron-star surface-ray behavior, and all authoritative data.
- Preserve DATA_DRIVEN semantics for Black-Hole Merger and Galaxy Collision.
- Preserve PROCEDURAL_SCIENTIFIC model equations for procedural destinations;
  presentation layers may only consume their resolved outputs.
- Keep WebGPU preferred with the existing WebGL2 fallback and one TSL graph
  wherever the backend contract permits it.
- Preserve seeded determinism. No `Math.random`, wall-clock shader state, or
  frame-order-dependent visual state in deterministic captures.
- Keep one global quality/governor authority. Cinematic detail must consume
  the existing effective quality tier and never create a private governor.
- Track and dispose every new geometry, material, texture, render target, and
  listener through the existing ResourceScope lifecycle.
- Do not claim completion from a single attractive screenshot. A slice needs
  unit, browser, backend, visual, console, and resource evidence.

## Validation contract

Every slice runs narrow tests first, then `npm run check`, affected browser
tests on the default and forced-WebGL2 paths, deterministic golden checks, and
browser console/device-loss checks. Any changed golden requires a written
reason and a twice-stable capture. Final certification must produce
`docs/VISUAL_FIDELITY_CERTIFICATION.md` with baseline/final SHAs, backend and
adapter, viewport/internal resolution, quality tier, screenshots reviewed,
known limitations, and deferred environment gates.
